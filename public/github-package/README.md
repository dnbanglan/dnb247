ডিএন বাংলা (DN Bangla) এর জন্য প্রস্তুতকৃত সম্পূর্ণ ব্রাউজার-ভিত্তিক হাই-রেজোলিউশন (1920x1920 PX) ফটোকার্ড জেনারেটর, দৈনিক অটো শিডিউলার, কর্মী তথ্যভাণ্ডার ও প্রেস আইডি কার্ড জেনারেটর, এবং ওয়ার্ডপ্রেস ও মাল্টি-সোশ্যাল মিডিয়া API ইন্টিগ্রেশন ইঞ্জিন। এটি কোনো ব্যাকএন্ড সার্ভার ছাড়াই সরাসরি যেকোনো ব্রাউজারে বা GitHub Pages-এ আজীবনের জন্য বিনামূল্যে লাইভ চলে।

---

## 🌟 প্রধান মডিউল ও সুবিধাসমূহ (Key Features)

### ১. ১৯২০x১৯২০ ফটোকার্ড ইঞ্জিন ও টেক্সট ট্রিগার
- **আল্ট্রা এইচডি স্কয়ার ক্যানভাস (1920x1920 PX):** ফেসবুক, ইনস্টাগ্রাম, এক্স (টুইটার), টিকটক ও টেলিগ্রামের জন্য পারফেক্ট রেশিও।
- **স্বয়ংক্রিয় লাইন-ব্রেকিং ও মার্জিন কন্ট্রোল:** ১, ২ বা ৩ লাইনে স্বয়ংক্রিয়ভাবে হেডলাইন ফন্ট সাইজ অ্যাডজাস্টমেন্ট।
- **ট্রিগার ফটোকার্ড:** ব্রেকিং নিউজ ও জরুরি ঘোষণার জন্য সেন্টার্ড টেক্সট ফটোকার্ড জেনারেটর।
- **লোকাল বিজ্ঞাপন রোটেটর:** ১৬৪০px থেকে ১৯২০px অ্যাডভার্টাইজমেন্ট ব্যানার সাইকেল এবং স্থায়ী ব্রাউজার স্টোরেজ।

### ২. দৈনিক সময়সূচি ভিত্তিক অটো শিডিউলার (Daily Routine Auto-Scheduler)
- **সকালের রুটিন (Morning Shift):**
  - ভোর ০৬:০০ টা &rarr; শুভ সকাল অনুপ্রেরণামূলক ফটোকার্ড
  - সকাল ০৬:৩০ টা &rarr; প্রতিদিনের সকালের আবহাওয়ার বার্তা কার্ড
  - সকাল ০৭:০০ টা &rarr; দৈনিক ৫ ওয়াক্ত নামাজের সময়সূচি ও সেহরি/ইফতার
  - সকাল ০৭:৪৫ টা &rarr; দৈনিক স্বাস্থ্য বুলেটিন ও সুস্থতার বার্তা
  - সকাল ০৮:১৫ টা &rarr; ইতিহাসে আজকের দিনে কি হয়েছিল
  - সকাল ০৮:৪৫ টা &rarr; গুরুত্বপূর্ণ বিশিষ্ট ব্যক্তিদের জন্মবার্ষিকী ও শ্রদ্ধাঞ্জলি কার্ড
- **দুপুরের রুটিন (Noon Shift):**
  - দুপুর ০১:৩০ টা &rarr; দুপুরের আবহাওয়ার তাপমাত্রা ও আর্দ্রতা ফটোকার্ড
  - দুপুর ০৩:০০ টা &rarr; সরকারি আবহাওয়া ঝুঁকি বা দুর্যোগ জরুরি আপডেট
- **রাতের রুটিন (Night Shift):**
  - রাত ১০:৩০ টা &rarr; ওয়েবসাইটে প্রকাশিত দিনের সেরা ১০টি (Top 10) নিউজের শিরোনাম দিয়ে টপ-টেন বুলেটিন কার্ড
- **টিগার ইন্টিগ্রেশন:** শিডিউলারের যেকোনো বুলেটিন এক ক্লিকে সরাসরি টেক্সট/ট্রিগার ফটোকার্ডে অথবা মূল ১৯২০x১৯২০ ফটোকার্ডে লোড করে অটো পোস্ট প্রস্তুত করা যায়।

### ৩. কর্মী তথ্যভাণ্ডার ও অটো প্রেস আইডি কার্ড জেনারেটর (Staff Directory & ID Card)
- **বিস্তারিত কর্মী ডেটাবেস:** নাম, পদবী, বিভাগ, আইডি নম্বর, রক্তের গ্রুপ, মোবাইল ও পাসপোর্ট সাইজ ফটো আপলোড।
- **কাস্টম ডিজাইনের ডিজিটাল প্রেস আইডি কার্ড:**
  - ফ্রন্ট সাইড (Front Side): অফিশিয়াল ডিএন বাংলা ব্যানার, ছবি, নাম, পদবী, রক্তের গ্রুপ ব্যাজ, অথরাইজড সিগনেচার ও QR কোড।
  - ব্যাক সাইড (Back Side): প্রেস কার্ডের আইনি শর্তাবলী, অফিসের ঠিকানা ও বারকোড।
  - এক ক্লিকে হাই-রেজোলিউশন (HD PNG) কার্ড ডাউনলোড।

### ৪. ওয়ার্ডপ্রেস ও সোশ্যাল মিডিয়া API সেটিংস (Multi-Platform API Suite)
- **WordPress REST API:** সাইট ইউআরএল, ইউজারনেম ও অ্যাপ্লিকেশন পাসওয়ার্ড দিয়ে অটো নিউজ ফেচ ও সিঙ্ক।
- **Facebook Page Graph API:** পেজ আইডি ও এক্সেস টোকেন দিয়ে সরাসরি পেজে ফটোকার্ড পোস্ট।
- **X (Twitter API v2):** API Key, Secret ও Access Token দিয়ে অটো টুইট।
- **Instagram Graph API:** ইনস্টাগ্রাম বিজনেস ফিডে ১৯২০x১৯২০ স্কয়ার কার্ড শেয়ারিং।
- **TikTok Open API:** টিকটক ক্যারোসেল ও ফটো পাবলিশিং।
- **WhatsApp Channel:** Meta WhatsApp Cloud API দিয়ে অফিশিয়াল চ্যানেলে ব্রডকাস্টিং।
- **Telegram Channel:** Telegram Bot Token ও চ্যানেল ইউজারনেম দিয়ে তাত্ক্ষণিক এইচডি ছবি পুশ।
- **Threads Graph API:** মেটা থ্রেডস অ্যাকাউন্টে অটো পাবলিশিং।
- **লোকাল স্টোরেজ সিকিউরিটি:** সকল ক্রেডেনশিয়াল ব্যবহারকারীর নিজস্ব ব্রাউজারে সুরক্ষিত থাকে।

## 🚀 GitHub Pages-এ ফ্রি লাইভ ওয়েবসাইট করার নিয়ম

1. **GitHub.com**-এ গিয়ে নতুন রেপোজিটরি তৈরি করুন (`dnbangla-photocard`)।
2. **"uploading an existing file"**-এ ক্লিক করে এই প্যাকেজের `index.html` ফাইলটি আপলোড করে Commit করুন।
3. রেপোজিটরির **Settings** &rarr; **Pages**-এ যান।
4. **Source:** `Deploy from a branch`, **Branch:** `main`, **Folder:** `/ (root)` দিয়ে **Save** করুন।
5. ১ মিনিটের মধ্যে আপনার লাইভ ওয়েবসাইট লিঙ্ক তৈরি হয়ে যাবে:  
   `https://<your-username>.github.io/dnbangla-photocard/`
